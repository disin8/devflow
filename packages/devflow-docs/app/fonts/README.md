# Fonts

Self-hosted webfonts used by the documentation site.

| File            | Family      | Weights | License                        |
| --------------- | ----------- | ------- | ------------------------------ |
| `inter.woff2`   | Inter       | 100–900 | SIL Open Font License 1.1     |
| `archivo.woff2` | Archivo     | 100–900 | SIL Open Font License 1.1     |
| `robotomono.woff2` | Roboto Mono | 100–700 | SIL Open Font License 1.1   |

The files are the variable `latin` subset builds published by Google Fonts.
They are self-hosted so that a build never depends on `fonts.googleapis.com`
being reachable and so the browser never issues a third-party request.

The SIL Open Font License 1.1 permits bundling the fonts with the site. The
full license text is available at <https://openfontlicense.org>.
