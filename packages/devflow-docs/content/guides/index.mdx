Every guide on this page solves one specific problem end to end. A guide shows the problem, the exact command, the files that end up in your repository, what the CI run looks like, and what the setup does **not** cover.

If you want the opposite view — what a single tool generates — go to the [module pages](/modules). A module page answers "what files does this create?", a guide answers "how do I solve this problem?".

## Lint and format

### [ESLint, Prettier and Husky setup for React and TypeScript](/guides/eslint-prettier-husky)

The three tools that belong together, in the order that avoids the classic "ESLint and Prettier disagree" bug. Includes the flat config, the `.prettierrc`, the pre-commit hook and the CI check.

```bash
npx create-devflow --lint --husky
```

## CI/CD

### [GitHub Actions CI/CD for Next.js](/guides/github-actions-nextjs)

A pull request pipeline that lints, type-checks, tests and builds a Next.js application — and where the deploy step actually belongs.

```bash
npx create-devflow --ci github
```
