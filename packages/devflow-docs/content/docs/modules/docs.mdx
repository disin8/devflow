## README.md

**Professional project README** — template with badges, sections, and structure.

[📖 Official Docs](https://www.makeareadme.com/)

- **ID:** `readme`
- **Category:** Docs

### What it does

Generates a `README.md` with:

- Project title and description badges
- Quick start section
- Installation instructions
- Usage examples
- Contributing link
- License section

## LICENSE

**License file** — choose the right license for your project.

[📖 Official Docs](https://choosealicense.com/)

- **ID:** `license`
- **Category:** Docs

### Options

| Option | Values                                   | Default |
| ------ | ---------------------------------------- | ------- |
| `type` | `"MIT"`, `"Apache-2.0"`, `"proprietary"` | `"MIT"` |

### What it does

Creates a `LICENSE` file with the selected license text, filled with the current year and project name.
