## Flags at a glance

| Flag              | Description                                       |
| ----------------- | ------------------------------------------------- |
| `--dry-run`       | Preview all changes without applying them         |
| `--all`           | Apply the recommended preset for the detected stack |
| `--only <module>` | Setup a single module by id                       |
| `-y, --yes`       | Skip all confirmations                            |
| `--skip-install`  | Create config files only, don't run the install   |
| `--pm <manager>`  | Force package manager (`npm`, `yarn`, `pnpm`, `bun`) |
| `--ci <provider>` | CI provider (`github`, `gitlab`, `both`)          |
| `--scope <pattern>` | Workspace glob pattern for monorepo configs      |
| `--verbose`       | Verbose output                                    |

## Module shortcuts

| Flag               | Applies                                                |
| ------------------ | ------------------------------------------------------ |
| `--husky`          | Husky, lint-staged, Commitlint                         |
| `--lint`           | ESLint, Prettier, EditorConfig                         |
| `--test`           | Vitest                                                 |
| `--docker`         | Dockerfile, docker-compose, .dockerignore              |
| `--docs`           | README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY.md, LICENSE |
| `--security`       | npm audit, Gitleaks                                   |
| `--release <tool>` | release-it, changesets or semantic-release             |
